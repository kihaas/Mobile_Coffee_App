# Mobile App for Coffee Store

This project is a mobile application developed for a coffee store, aiming to enhance customer experience through a user-friendly interface and seamless functionality.

---

## 📱 Project Overview

The mobile app serves as a digital platform for customers to interact with the coffee store. It provides features such as:
- **Product Catalog**: Browse through a variety of coffee offerings.
- **Order Placement**: Select and customize orders.
- **User Authentication**: Secure login and registration system.
- **Order History**: View past orders and reorder with ease.

The app is designed to streamline the ordering process, making it convenient for customers to enjoy their favorite beverages.

- **Frontend**: Kotlin (Android Development)
- **Backend**: Firebase (Authentication, Firestore Database)
- **Authentication**: Firebase Authentication
- **Database**: Firebase Firestore

## 🚀 Getting Started

### Prerequisites

- Android Studio installed
- Firebase project set up
- Google Services JSON file (`google-services.json`)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/kihaas/mobile_app.git
   cd mobile_app
   ```
2.Open the project in Android Studio.

3.Add your google-services.json file to the app/ directory.

4.Sync the project with Gradle files.

5.Run the application on an emulator or physical device.
